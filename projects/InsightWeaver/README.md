# InsightWeaver - Autonomous Data Analysis Agent

## Overview:
An intelligent system designed to automate the end-to-end workflow of exploratory data analysis (EDA), data cleaning, and insight generation.

## Phases:
- Phase 1: Environment setup & API initialization
- Phase 2: LangGraph state & Ingestion/Planner nodes
- Phase 3: Tool-calling & Execution node
- Phase 4: Reporting node & end-to-end testing
